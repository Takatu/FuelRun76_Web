# Fuel Run '76 — Web prototype

A playable browser prototype of **Fuel Run '76** (working title), a roguelike vehicular combat game in the spirit of Interstate '76. It exists to test the run loop, pacing and feel before the Unreal Engine 5 build.

Open `index.html` in a browser to play. No build step and no dependencies apart from Google Fonts.

## What's in it

- **Garage:** four cars (Coupe, Pickup, Pony car, Land yacht). The Coupe is open from the start; the others unlock through challenges. Unlocks are saved in the browser.
- **Route map:** three legs. Desert first, then Rockies or Lava fields, then the Louisiana bayou. Each run gets a random season that changes grip and weather.
- **Stops:** Ambush, Chase, Defend, truck stops, roadside events, and a boss at the end of each leg.
- **Systems:** fuel spent per stop, armor on four sides plus hull damage that carries over, ram damage, mines, homing rockets, repair kits, six run mods, and a time of day that moves from dawn to night.

## Controls

| Action | Keyboard |
| --- | --- |
| Accelerate | W / ↑ |
| Brake / reverse | S / ↓ |
| Steer | A D / ← → |
| Machine gun | Space |
| Drop mine | E |
| Rocket | F |
| Repair kit | R |
| Nitro (Pony car) | Q |
| Pause | P / Esc |

On a touch screen, on-screen buttons appear instead.
